# Negocio

**Misión:** que el proyecto se pague solo y deje algo de beneficio, cumpliendo la EULA de Mojang.

## Costes (aprox.)
| Concepto | €/mes |
|----------|-------|
| PebbleHost (8 GB) | ~9 |
| Railway (AmberBot) | ~4,5 (5 USD; el saldo que sobra se acumula) |
| **Total** | **~13,5 (~160 €/año)** |

## Objetivos de ingresos
- **Cubierto:** ~15 €/mes.
- **Con margen:** ~25 €/mes (p. ej. 5 apoyos de 3 € y 2 de 5 €).

## Restricciones de la EULA y las Usage Guidelines de Mojang
- Se permiten los cosméticos y las donaciones; no se permite vender ventajas de juego.
- Todos los jugadores pagan el mismo precio por lo mismo.
- No dar a entender que Mojang o Microsoft respaldan el servidor.

## Estado actual
- Ya existe el rol **Supporter** (internamente `patreon`). No se sabe todavía cómo se cobra ni qué recibe exactamente.
- ⚠️ **Riesgo:** Supporter da más chunks protegidos (32 frente a 20). Si va ligado a pagar, puede ser una ventaja de juego. **Revisar antes de monetizar.**
